# Using and citing the outputs

## Browse

Use [Textual Collations](https://tabpub.elte.hu/collation/results.php) to explore the current Approved material. Coverage grows as research is approved.

## Reuse a fixed dataset

Use a deposited publication package for an analysis that must be repeatable. Record the dataset version and version-specific DOI, retain its source references and distinguish attested readings from scholarly reconstructions.

Use the package's SHA256SUMS.txt to check file integrity. JSON provides the records for analysis; JSON-LD supports graph-based processing. Neither format requires access to the hosted editorial application to read the published records.

## Citation

Cite the actual creators, title, version and DOI supplied by the dataset deposit. Cite relevant publications and source editions where required. The project website or this documentation is not a substitute for a dataset citation.

Dataset citation information is supplied by the corresponding deposit. Documentation authorship and dataset authorship need not be identical.

## Reproducibility boundary

The documentation repository does not contain the complete editing application. Published data can be inspected independently, but reproducing every operation of the hosted system requires additional implementation information. Any analysis on which a publication relies should identify its inputs, methods, parameters and the relevant scripts or software versions.
